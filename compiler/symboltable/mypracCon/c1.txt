Task 1
Create a command called DT (Delete Type). This will take an argument - type. Example -
DT INT
This will delete all symbols (in the entire symbol table) with the given type - INT
Task 2
Create a command called IS which is used to insert a scope-local symbol. These are symbols
that are only visible to their own container scope but neither by their descendant scopes
nor by their ancestor scopes. For example, consider the following example -
1 int x; ----> let's say x is a scope-local symbol
2 {
3 ----> x is invisible here
4 }
Here if x is a scope-local symbol then it won’t be visible in line 3. Because line 3 is in a
descendant scope of the scope-local variable.
Restrictions
•You can add any attribute to any existing classes.
•STL not allowed
•Must compile with -fsanitize=address

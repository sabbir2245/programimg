# SymbolTableSpec

Symbol table implementation with online problem solutions (A1, B1, C1).

## Structure

- `symboltable/` — Symbol table code, solutions, and docs
- `assembly/` — Assembly programs
- `old_codes.7z` — Archived old code backups

## Build

```bash
g++ -fsanitize=address -o symboltable symboltable/2205040_symbol_table.cpp
```
